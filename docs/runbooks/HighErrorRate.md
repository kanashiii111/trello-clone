# HighErrorRate

**Что значит.** Больше 5% запросов к приложению 2 минуты подряд
завершаются ошибкой 5xx (при трафике больше 0.2 RPS).

**Как проверить.**
- Дашборд «Обзор сервиса» → «Errors: доля ответов 5xx»: какой `route` даёт ошибки.
- В Prometheus: `sum by (route, status) (rate(http_requests_total{status=~"5.."}[5m]))`.
- `docker compose logs php` — текст ошибок PHP.

**Что делать.**
- Ошибки по одному route — смотреть код этого скрипта и последний деплой.
- По всем route сразу — общая зависимость: БД (PostgresDown?), переполнение пула.
- Если причина в свежем изменении — откатить, разбираться потом.

**Воспроизвести.** Несколько минут подряд запрашивать ошибочный эндпоинт:
`while true; do curl -s -o /dev/null http://127.0.0.1:8080/demo/error.php; sleep 0.2; done`.
Обратите внимание на `for: 2m` при окне `rate[1m]`: всплеск ошибок короче минуты
алерт не поднимет — он дойдёт до pending и погаснет.
